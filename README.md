# Revisão de literatura com IA

Página de apoio sobre como fazer revisão de literatura e síntese de evidências com IA, com rastreabilidade entre fonte e conclusão.

- `index.html`: a página, com o caminho de trabalho, erros e soluções, um exemplo conferido, ferramentas e o kit.
- `downloads/`: skill para o Claude, instruções para assistentes, kit do agente (Claude Code ou Codex), planilha, prompts e checklist.

Publicada pelo GitHub Pages.
